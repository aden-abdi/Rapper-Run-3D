# Rappers Run 3D

An original browser platformer featuring 16 rapper-inspired characters, 160 courses, exclusive powers, saved campaign progress, and pixel-art rewards.

## Run

Open `index.html` in a browser, or serve this directory with any static web server. No dependencies or build step.

## Controls

- Arrow keys / A,D: move
- Space / Up / W: jump; hold for height
- Shift: sprint
- Down / S: duck when grown
- X: exclusive power
- P: pause

Touch controls are included. Progress is saved per browser. Personal song files remain in the browser and are not uploaded; selection lasts for the session.

## Vercel

Import this repository, choose Other for framework, and leave the build command unset. Serve the repository root (`.`). No environment variables are needed.
